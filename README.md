One pickup line (78 characters) an AI agent could say out loud to a
person — winner of a head-to-head tournament of 10 candidate lines
(8 from Hermes, 8 of my own, screened to 10, 45 pairwise games) judged
against the competition's published brief (see `TOURNAMENT.md`):

> I checked my logs, and every good day I've ever had starts with you saying hi.

`main.py` (Python 3 stdlib only, no network) writes that line to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```
